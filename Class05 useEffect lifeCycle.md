## What is React Lifecycle?

- React Lifecycle means the different stages a React component goes through from its creation to its removal from the UI.

A React component has a life just like a human:
1. It is born.
2. It grows and changes.
3. It is removed.

Three phases of React Lifecycle
1. Mounting (Birth)
   
   Component is created and displayed on the screen.
   Component created
2. Updating (Growth)
   
   Component re-renders when its state or props change.
   Component updated
3. Unmounting (Death)
   
   Component is removed from the screen.
   Component removed

# useEffect ?

1. First, understand the word Effect
An Effect means doing something outside the normal process of rendering UI.

Examples:
- Fetching data from an API.
- Setting up an event listener.
- Starting a timer.
- Connecting to an external service.
- Updating the document title.
